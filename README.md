# Plataforma de Monitoramento e Análise de Editais para Concursos Públicos de TI

Este projeto documenta a estrutura inicial de engenharia de requisitos para uma plataforma web voltada ao rastreamento, monitoramento e análise de editais de concursos públicos relacionados à área de Tecnologia da Informação.

## Objetivo

Permitir que usuários acompanhem editais, recebam alertas sobre novas vagas, filtrem oportunidades por banca examinadora e acompanhem retificações de forma organizada.

## Estrutura do projeto

- [analise](analise): documentos de análise de necessidades e regras de negócio.
- [especificacao](especificacao): cenários, critérios de aceitação e histórias de usuário.
