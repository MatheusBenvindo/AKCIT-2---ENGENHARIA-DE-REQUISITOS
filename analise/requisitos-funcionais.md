# Requisitos Funcionais

## RF01 - Cadastro de edital
O sistema deve permitir o cadastro de editais de concursos públicos com informações como título, órgão, data de publicação, banca examinadora, vagas, link e observações.

## RF02 - Monitoramento automático
O sistema deve verificar periodicamente novas publicações e alterações em editais já conhecidos.

## RF03 - Cadastro de alertas de vagas
O usuário deve conseguir cadastrar alertas para palavras-chave, áreas de TI e tipos de vaga.

## RF04 - Filtros de busca
O sistema deve possibilitar filtragem por órgão, cargo, localidade, banca examinadora, data de publicação e status do edital.

## RF05 - Leitura de retificações
O sistema deve disponibilizar uma visão consolidada das retificações associadas a um edital, incluindo data e resumo das mudanças.

## RF06 - Histórico de acompanhamento
O usuário deve visualizar o histórico de editais acompanhados, incluindo alterações e alertas recebidos.
