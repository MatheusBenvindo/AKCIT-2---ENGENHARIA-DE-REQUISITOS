# Regras de Negócio

## Regras principais

1. Todo edital cadastrado deve possuir identificação única, data de publicação, órgão responsável e link oficial.
2. O sistema deve identificar automaticamente alterações em editais já cadastrados, como retificações, acréscimos de vagas e mudança de datas.
3. Usuários cadastrados podem criar alertas com base em palavras-chave, áreas tecnológicas e regiões de interesse.
4. Um alerta deve ser disparado quando uma vaga compatível com os critérios do usuário for publicada ou atualizada.
5. Editais com status de cancelado ou revogado devem receber marcação explícita no painel do usuário.

## Exemplo prático

Se um edital de concurso público para Analista de Redes for publicado em uma banca examinadora específica, o sistema deve registrar esse edital e notificar usuários que configuraram alertas para "redes", "analista" e "estadual".
