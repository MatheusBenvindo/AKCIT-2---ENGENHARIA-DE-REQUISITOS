# Ambiguidades e Lacunas

## Ambiguidades identificadas

1. **Definição de "vagas relevantes"**
   - O usuário pode entender vaga relevante de formas diferentes, como cargos de analista, desenvolvedor, suporte ou arquiteto.

2. **Origem dos editais**
   - O sistema precisa indicar claramente se o edital foi extraído de uma fonte oficial, de um portal governamental ou de um agregador.

3. **Critério de alerta**
   - Nem todos os usuários desejam receber alertas para todos os tipos de vagas; é necessário definir filtros por área, cargo e localidade.

## Lacunas a esclarecer

- Como serão tratados editais duplicados ou versões antigas.
- Qual o prazo para atualização automática dos dados após publicação de retificações.
- Quais perfis de usuário podem configurar alertas personalizados.
- Como o sistema deve registrar a leitura de novas informações por parte do usuário.
