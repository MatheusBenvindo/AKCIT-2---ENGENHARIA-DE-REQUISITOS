# Casos de Uso

## UC01 - Cadastrar edital
Ator: Administrador ou sistema de integração

Objetivo: registrar um novo edital de concurso público no sistema.

Fluxo principal:
1. O usuário informa os dados do edital.
2. O sistema valida as informações.
3. O edital é salvo e disponibilizado para consulta.

## UC02 - Cadastrar alerta de vaga
Ator: Usuário

Objetivo: receber notificações sobre vagas compatíveis com critérios escolhidos.

Fluxo principal:
1. O usuário define palavras-chave e filtros.
2. O sistema armazena o alerta.
3. O sistema dispara notificação quando houver correspondência.

## UC03 - Filtrar editais por banca examinadora
Ator: Usuário

Objetivo: localizar editais publicados por uma banca específica.

Fluxo principal:
1. O usuário seleciona a banca examinadora no filtro.
2. O sistema retorna a lista correspondente.
3. O usuário visualiza os detalhes do edital selecionado.

## UC04 - Ler retificação de edital
Ator: Usuário

Objetivo: consultar mudanças posteriores a um edital já cadastrado.

Fluxo principal:
1. O usuário acessa o edital.
2. O sistema exibe as retificações disponíveis.
3. O usuário analisa as alterações aplicadas.
